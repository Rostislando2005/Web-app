История создания

SQL (англ. Structured Query Language — «язык структурированных запросов») — декларативный язык программирования, который применяется для создания, изменения и управления данными в реляционных базах данных.

Основой для SQL стала реляционная модель данных, которую в 1970 году описал сотрудник компании IBM Эдгар Кодд в своей статье. После этого в IBM начали работу над экспериментальной СУБД System R, и для неё был нужен удобный язык запросов.

В начале 1970-х годов Дональд Чемберлин и Рэймонд Бойс разработали язык SEQUEL (Structured English Query Language). Позже его пришлось переименовать в SQL, потому что название «SEQUEL» уже было торговой маркой другой компании. Поэтому до сих пор многие произносят SQL как «сиквел».

Первой коммерческой СУБД с поддержкой SQL стала Oracle V2 в 1979 году. В 1986 году SQL был принят как стандарт ANSI, а в 1987 году — как стандарт ISO. С тех пор стандарт много раз обновлялся. Основные версии стандарта приведены в таблице ниже.

Краткий обзор языка

SQL — это декларативный язык: программист пишет, что нужно получить, а не как это сделать. Как именно найти данные, решает сама СУБД. Все данные хранятся в таблицах, которые состоят из строк (записей) и столбцов (полей).

Основные группы команд SQL

  1. DDL (Data Definition Language) — описание структуры: CREATE, ALTER, DROP.
  2. DML (Data Manipulation Language) — работа с данными: SELECT, INSERT, UPDATE, DELETE.
  3. DCL (Data Control Language) — права доступа: GRANT, REVOKE.
  4. TCL (Transaction Control Language) — транзакции: COMMIT, ROLLBACK.

Популярные СУБД, которые используют SQL

  • MySQL
  • PostgreSQL
  • SQLite
  • Microsoft SQL Server
  • Oracle Database

Основные типы данных

  • INT — целые числа
  • DECIMAL — дробные числа с фиксированной точностью
  • VARCHAR(n) — строка длиной до n символов
  • DATE — дата
  • BOOLEAN — логическое значение
Первичный ключ (PRIMARY KEY)
Поле, которое однозначно определяет каждую строку таблицы.
Внешний ключ (FOREIGN KEY)
Поле, которое ссылается на первичный ключ другой таблицы.

Примеры кода

1. Создание таблицы

-- создаём таблицу студентов
CREATE TABLE students (
    id    INT PRIMARY KEY,
    name  VARCHAR(50) NOT NULL,
    age   INT,
    grp   VARCHAR(10)
);

2. Добавление данных

INSERT INTO students (id, name, age, grp)
VALUES (1, 'Анна', 19, 'КИ23-01'),
       (2, 'Иван', 20, 'КИ23-01'),
       (3, 'Олег', 18, 'КИ23-02');

3. Выборка данных

-- студенты старше 18 лет, отсортированные по имени
SELECT name, age
FROM students
WHERE age > 18
ORDER BY name;

4. Группировка

SELECT grp, COUNT(*) AS cnt, AVG(age) AS avg_age
FROM students
GROUP BY grp;

5. Изменение и удаление

UPDATE students SET age = age + 1 WHERE id = 3;
DELETE FROM students WHERE grp = 'КИ23-02';

Результат запроса из примера 3:
Анна | 19
Иван | 20
